# YouTube Clone

A responsive **YouTube homepage clone** built using **HTML and CSS**.
The project recreates the core visual layout of YouTube, including the navigation sidebar, search bar, video cards, thumbnails, and responsive behavior across different screen sizes.

## 📸 Preview

![Visit YouTube Clone](youtube-clone-wine-omega.vercel.app)

## 🚀 Features

* Responsive YouTube-style layout
* Desktop and mobile-friendly design
* YouTube-inspired navigation sidebar
* Search bar with search and microphone icons
* Video thumbnail grid
* Video title, channel name, views, and upload time
* Channel profile images
* Responsive video card layout
* Header navigation with icons
* Clean and structured HTML/CSS

## 🛠️ Technologies Used

* **HTML5** — Page structure and semantic elements
* **CSS3** — Styling, layout, responsiveness, and positioning

### CSS Structure

The CSS is separated into multiple files to keep the project organized:

* `general.css` — General page styling and common CSS rules
* `header.css` — YouTube header and search bar styling
* `sidebar.css` — Navigation sidebar styling
* `video.css` — Video grid, thumbnails, titles, and video information styling

## 💻 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/your-username/youtube-clone.git
```

### 2. Open the project

Navigate into the project folder:

```bash
cd youtube-clone
```

### 3. Run the project

Open `youtube.html` directly in your browser.

You can also use **VS Code Live Server** for development.

## 📱 Responsive Design

The layout is designed to adapt to different screen sizes using CSS responsive techniques.

The video grid adjusts according to the available screen width, while the navigation and header elements adapt for smaller devices.

## 🎯 Project Goal

The goal of this project was to practice building a real-world website interface from scratch while improving understanding of:

* HTML page structure
* CSS layouts
* Flexbox and Grid
* Responsive web design
* Reusable UI components
* Image and icon positioning
* Creating layouts based on an existing design
